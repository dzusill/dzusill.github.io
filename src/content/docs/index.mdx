## Welcome 👋

Glad you're here! Whether you're spinning up your first plugin or fine-tuning a packed server, you're in the right place. Every dzusill plugin is documented the same friendly way, so once you know one, you know them all:

- 🚀 **Getting Started** — install it and have it running in minutes.
- ✨ **Features** — every feature explained, with examples.
- ⚙️ **Configuration** — every config key, what it does, and sensible defaults.
- 📖 **Reference** — commands, permissions, placeholders and FAQs at a glance.

Jump straight to whatever plugin you're running below — they're grouped by what they do. 🔍 The search bar (top right) finds anything across every plugin.

## The plugins

### 🛠️ Framework

The base everything else is built on.

| Plugin | What it does |
| --- | --- |
| [🛠️ DzusillCore](/plugins/dzusillcore/) | Reusable Paper plugin template framework |
| [💬 DDialogs](/plugins/ddialogs/) | Native Minecraft dialog screens for every DzusillCore plugin |

### 🌙 Oberon Suite

The plugins written for the Oberon server, each usable on its own.

| Plugin | What it does |
| --- | --- |
| [🧰 OberonUtils](/plugins/oberonutils/) | Eight switchable modules in one jar — teleports & warps, key-all crates, kill confirmation, night vision, `/ping`, combat cooldowns, super jump and elytra limits |
| [🛡️ OberonChat](/plugins/oberonchat/) | Chat filter that folds leetspeak, spacing & lookalikes before matching — and reads commands, signs, books & anvils |
| [📣 OberonAnnounce](/plugins/oberonannounce/) | Rotating and scheduled announcements with clickable lines — interval, daily and weekly schedules that hold through a daylight-saving change |
| [📡 OberonLive](/plugins/oberonlive/) | Safe live-stream announcements with player opt-outs, platform validation, H2/MySQL history, moderation and Discord webhooks |
| [🪣 OberonTools](/plugins/oberontools/) | Custom tools defined entirely in config — a liquid absorber and a tree feller, with expiry timers and permission-tiered radius |
| [✉️ OberonMSG](/plugins/oberonmsg/) | Private messages with UUID-keyed ignore lists, social spy & vanish-aware delivery |
| [🎖️ OberonStaff](/plugins/oberonstaff/) | Staff chat, the full teleport suite & vanish visibility that holds in tab completion too |
| [🔒 OberonWhitelist](/plugins/oberonwhitelist/) | Command & tab whitelist that keeps menus working — one error for everything a player may not run |
| [💀 OberonKills](/plugins/oberonkills/) | Death messages that name the weapon and spell the item properly |
| [🐺 OberonMob](/plugins/oberonmob/) | Per-player mob & phantom spawn toggles, with a choice of cancelling the spawn or hiding it |
| [📈 OberonStats](/plugins/oberonstats/) | Stats & leaderboard placeholders for currencies, Vault money and vanilla statistics — other players' numbers, and empty rows that vanish instead of showing zeros |
