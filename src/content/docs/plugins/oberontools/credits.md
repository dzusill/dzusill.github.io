**OberonTools** by **dzusill**, built on the [DzusillCore](https://github.com/dzusill/DzusillCore) framework (shipped as OberonCore).

- Text, names and lore: [Kyori Adventure / MiniMessage](https://docs.advntr.dev/minimessage/format.html)
- Server platform: [PaperMC](https://papermc.io/)
- Optional soft dependencies: [WorldEdit](https://enginehub.org/worldedit), [WorldGuard](https://enginehub.org/worldguard) — neither is called directly; protection works through `BlockBreakEvent`

Found a bug or have a feature idea? Open an issue on the project repository.
