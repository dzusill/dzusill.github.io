**OberonAnnounce** by **dzusill**, built on the [DzusillCore](https://github.com/dzusill/DzusillCore) framework (shipped as OberonCore).

- Text, colours and gradients: [Kyori Adventure / MiniMessage](https://docs.advntr.dev/minimessage/format.html)
- Server platform: [PaperMC](https://papermc.io/)
- Optional soft dependency: [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) by extendedclip — every announcement line is passed through it when it is installed

Written for the Oberon SMP network; the shipped `config.yml` is that server's live configuration.
