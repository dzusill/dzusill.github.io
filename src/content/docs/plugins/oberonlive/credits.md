OberonLive is developed by **dzusill** for the Oberon plugin suite.

- Built on [DzusillCore](https://github.com/dzusill/DzusillCore), deployed as **OberonCore**.
- The requested feature baseline was inspired by the public behavior of [PerfLive](https://builtbybit.com/resources/perflive-cool-media-rank-perk.98262/); OberonLive is a new implementation with its own architecture, H2/MySQL schema, safety rules, moderation, history and Discord integration.
- Optional placeholder interoperability is provided through [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/).
- Minecraft components use the MiniMessage/Adventure stack exposed by OberonCore.

No PerfLive source code or database migration is part of OberonLive.
