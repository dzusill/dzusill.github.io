## Built on

- [DzusillCore](https://dzusill.github.io/plugins/dzusillcore/) — modules, config merging, MiniMessage messages, command framework and Folia-aware scheduling.
- [Paper](https://papermc.io/) — server API.
- [LuckPerms](https://luckperms.net/) — optional, used for primary group and prefix in profile sync.

## Support

When reporting an issue, include:

- server version and platform
- dWebLink and DzusillCore versions
- whether LuckPerms is installed
- the exact message the player saw
- the console lines around the failure (with `api-key` redacted)
