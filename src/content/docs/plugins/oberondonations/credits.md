**OberonDonations** by **dzusill**, built on the [DzusillCore](https://github.com/dzusill/DzusillCore) framework (shipped as OberonCore).

- Text, colours, gradients and the inline donor head: [Kyori Adventure / MiniMessage](https://docs.advntr.dev/minimessage/format.html)
- Server platform: [PaperMC](https://papermc.io/)
- Store integration: [Tebex](https://tebex.io/) Plugin API — read-only, delivery stays with Tebex's own plugin
- Optional soft dependencies: [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) by extendedclip, [Vault](https://www.spigotmc.org/resources/vault.34315/) for GG Wave money rewards, [FancyNpcs](https://modrinth.com/plugin/fancynpcs), [ZNPCsPlus](https://modrinth.com/plugin/znpcsplus) or [Citizens](https://www.spigotmc.org/resources/citizens.13811/) for full-body donation boards
- The predecessor this plugin replaces: PerfDonation, whose SQLite history it imports on first run

Written for the Oberon SMP network; the shipped `config.yml` is that server's live configuration.
