**DSell** is developed by [dzusill](https://github.com/dzusill).

Built on the [DzusillCore](https://github.com/dzusill/DzusillCore) framework, which handles the module
lifecycle, configs, menus, commands, messages and scheduling.

## Built with

| | |
|---|---|
| [Paper](https://papermc.io/) | The server API |
| [Vault](https://github.com/MilkBowl/VaultAPI) | Economy abstraction |
| [Adventure](https://docs.advntr.dev/) | MiniMessage text |
| [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) | Optional placeholders |
| [bStats](https://bstats.org/) | Anonymous usage metrics |
| [MockBukkit](https://github.com/MockBukkit/MockBukkit) | Server mock for the test suite |

## Companion plugins

- [DRotatingShop](/plugins/drotatingshop/) — the rotating GUI shop DSell derives its prices from.

## Metrics

bStats collects anonymous server statistics — version, player count, server software. Opt out in
`plugins/bStats/config.yml`.

## Support

Issues and feature requests: [github.com/dzusill](https://github.com/dzusill).
