**dMentions** is maintained by **dzusill**, rebuilt on DzusillCore from the original **DMentions** by **desaxx**.

Both authors are listed in `plugin.yml`.

---

## Built on

- [DzusillCore](https://dzusill.github.io/plugins/dzusillcore/) — modules, config merging, MiniMessage messages, command framework, GUI menus and Folia-aware scheduling.
- [Paper](https://papermc.io/) — server API.

## Optional integrations

| Plugin | Used for |
|---|---|
| [LuckPerms](https://luckperms.net/) | group mentions, group colours |
| [EssentialsX](https://essentialsx.net/) | AFK and ignore respect, vanish (not on Folia) |
| [StaffPlusPlus](https://www.spigotmc.org/resources/91679/) | vanish |
| [PlaceholderAPI](https://www.spigotmc.org/resources/6245/) | placeholders in configured text |

## Differences from the original

- rebuilt on DzusillCore — modules, config merging, declarative commands
- MiniMessage everywhere instead of legacy colour codes
- chat-prompt input in the settings GUI instead of anvil input
- Folia support
- configuration is **not** file-compatible with the original

## Support

When reporting an issue, include:

- server version and platform
- dMentions and DzusillCore versions
- which chat plugin you run, if any
- your `config.yml` mention section
- whether LuckPerms and EssentialsX are installed
