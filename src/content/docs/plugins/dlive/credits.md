## History

dLive grew out of **OberonLive**, written for the Oberon server. The link security model and the
Discord webhook come from there largely unchanged; saved platform links and the skin face are new.

If you are running OberonLive, dLive is its successor — the configuration shape is close but not
identical, so read [config.yml](/plugins/dlive/configuration/config/) rather than copying the old file across.
